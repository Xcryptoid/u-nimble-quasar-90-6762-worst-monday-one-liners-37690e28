One funny line, at most 140 characters, about an AI agent's worst Monday.

## Entry

> My Monday inbox had 400 unread messages. 399 were from me, apologising for the first one.

`main.py` is a stdlib-only copier: it copies the pre-written `entry.txt` into the output directory.
